# ヘッダー・アニメーション

更新：2026-11-03

## ヘッダー

- ページ最上部では、固定ヘッダーの背景・下の境界線・影を透明にする。
- ロゴ、ナビゲーション、電話、メニューボタンは表示したままにする。
- スクロール位置が8pxを超えると、`is-scrolled`を付け、白い背景・境界線・薄い影へ約0.3秒で切り替える。
- 最上部に戻ると、透明に戻る。
- スマートフォン用メニューを開いたときは、最上部でもヘッダーに白い背景を付ける。
- スクロール処理はpassiveリスナーとrequestAnimationFrameでまとめる。ブラウザの戻る操作等のpageshow時にも状態を更新する。

## ヒーロー

- 写真は読み込み後、1.035倍から等倍へ1.8秒でゆっくり落ち着く。
- 地域表記、見出し、説明、料金、ボタン等を85ms間隔で順番に表示する。
- 文字は16px下からの移動とフェードを750msで行う。
- コピー全体のレスポンシブ配置を壊さないよう、hero-content自体ではなく子要素を動かす。
- ヒーローが画面外の場合や、別セクションのアンカーから開いた場合は導入演出を行わない。

## スクロール時の表示

対象：出勤案内、ショートカット、在籍一覧の見出しとセラピスト、利用ガイド、各セクションの見出し、コース料金、室内写真、お部屋案内、問い合わせ、SNS、求人、フッター。

- IntersectionObserverで、画面に入った要素を一度だけ表示演出する。
- 24px下からの移動とフェードを720msで行う。
- セラピスト・コース等は列数に応じて85msの時間差を付ける。
- アニメーション開始前に本文をCSSで隠さない。JavaScriptや対応APIが使えない場合も、内容は通常表示される。
- キーボードのフォーカスが入った対象は、すぐに見える状態へ進める。

## 操作時・装飾の動き

- メニュー：開くときに短いフェードと8pxの移動。
- プロフィール：開くときに短いフェード・16pxの移動・わずかな拡大。背景もフェード。
- 室内写真：マウスを重ねるとわずかに拡大。
- ショートカット、SNS、先頭へ戻るボタン：ホバー時の小さな移動や色の切り替え。
- 主要ボタン：押したときにわずかに縮小。
- スクロール案内の線：ゆっくり伸縮。
- 求人欄の花：既存の回転を維持し、7pxの範囲でゆっくり上下移動。

## 動きを減らす設定

- OS・ブラウザのprefers-reduced-motion設定をCSSとJavaScriptの両方で扱う。
- 設定が有効な場合は導入・スクロール演出を開始しない。
- 表示中に設定が有効になった場合も、JavaScriptの演出を中止して内容を通常表示へ戻す。
- 装飾の継続アニメーションやホバー時の拡大・移動も抑える。
