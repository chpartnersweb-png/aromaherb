# 構成の見直しと画像差替え

更新：2026-11-03

## 今回の依頼

- 現行ページの構成を考え直す。
- 在籍セラピストの画像には、ユーザーが添付した画像を使う。
- 6名に対して7枚あったため対応を確認。ユーザーの「足りてるならそれは使用しなくていい」という回答を受け、追加のcast08は使わない。
- 実装後の確認はユーザーが行うという前回の指定を継続する。

## 構成の軸

人物写真、出勤情報、コース料金、電話窓口へ短い操作で進める構成にする。
白・ピンク・花の雰囲気は既存のアメブロを基準とし、全画面ヒーロー、店舗名入りロゴ、専用favicon・OGPの方針も引き継ぐ。

## 新しいページの順序

| 順序 | 内容 | 目的 |
| --- | --- | --- |
| 1 | 全画面ヒーロー | 専用の横長・縦長画像と短いコピーで雰囲気を伝える。セラピスト一覧へ案内 |
| 2 | 出勤情報・ショートカット | アメブロと、セラピスト・料金・場所への入口をまとめる |
| 3 | 在籍セラピスト一覧 | 添付画像を主役に、名前・身長・短い紹介項目を見せる。タップでプロフィールへ |
| 4 | コース・料金 | 4コースを比較しやすく並べ、延長料金をすぐ下に表示 |
| 5 | お部屋・アクセス・電話 | 2部屋の公開範囲の住所と、問い合わせ窓口をまとめる |
| 6 | SNS | Instagram・アメブロへ案内 |
| 7 | セラピスト募集 | 提供済みの勤務条件・講習と電話窓口を掲載 |
| 8 | フッター | ロゴ、営業時間、ページ内メニュー |

## 見せ方の変更

- ヒーロー下の挨拶文だけの帯を取り除き、出勤と利用案内への入口を配置した。
- 在籍一覧の見出しを「在籍セラピスト」と明確にした。
- 一覧はパソコン3列、スマートフォン2列。長い紹介文はプロフィール内へまとめ、一覧では写真と名前を探しやすくした。
- パソコンでは一覧の横に、営業時間・定休日・エリア・料金の目安・電話・アメブロの利用ガイドを表示する。
- スマートフォンではサイドのガイドを省き、画面下のセラピスト・電話ボタンとページ内の案内を使う。
- 料金をパソコン4列、スマートフォン2列の比較表示にした。
- 横長の添付画像をプロフィールで縦長に切り取らず、元の縦横比で全体が見えるようにした。
