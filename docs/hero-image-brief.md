# 採用ヒーロー画像・デバイス対応

更新：2026-11-03

## 採用方針

ユーザーが比較用3候補の「1枚目・A案」をデスクトップ用として選択。
座った鏡越しの自撮り、黒髪、ピンクのニット、アイボリーのスカート、ピンクのハート、ベージュの室内という雰囲気を引き継ぐ。
タブレット・スマートフォン用はA案を参照し、それぞれの画面に合わせて専用生成した。
以前のソファでくつろぐ他撮り等の方向は採用しない。

## デバイスごとの構図

- デスクトップ：A案を使用し、人物の右側の余白にコピーを配置。
- タブレット：3:4。A案と同じ人物・衣装・座った自撮りを、上半身を中心に収め、中央右側と下部に明るい余白を設けた。
- スマートフォン：9:16。上側に人物、下側にコピーとボタン用の明るい余白。
- タブレットの縦横の向きに応じて、画像の表示位置とコピーの配置を調整。

## 表示

- pictureとプリロードの指定で画面幅ごとに画像を切り替える。
- 画像は縦横比を保ち、画面の表示範囲を埋める。
- ヒーローの高さは100svhを基本にする。
- ヘッダーは重ねて表示し、独立した店舗名の重複表示は省く。
- コピー・ボタン・「イメージ画像」の注記はHTML側で重ねる。

## 室内写真との区別

ヒーロー内の室内は生成イメージ。
ユーザー提供の室内写真3点は「お部屋・アクセス」欄のギャラリーに掲載する。
写真と水前寺・本荘の対応は未指定のため、個別の部屋名を付けない。

## 作業状況

画像の保存・参照の切替・デバイスごとの配置・室内ギャラリーをソースへ反映済み。
ユーザーの指示に従い、ビルド・テスト・開発サーバー起動・ブラウザでの表示確認・公開は行っていない。
